Code: q1d_simulated_annealing.py  
Problem formulation
- State: a full 4x4 grid. Givens never change, and each 2x2 box always
  contains 1-4 exactly once.
- Initial state: each box's missing digits placed in random order.
- Neighbour: swap two non-given cells inside a random box.
- Cost: number of repeated digits over all rows and columns
  (4 - distinct digits, per row/column). Boxes are never violated.
- Goal: cost = 0.

Design decisions
- Acceptance (lecture rule): always accept a better neighbour; otherwise
  accept with p = exp(-delta / T), delta = new cost - current cost.
- Cooling: T = T * alpha after every step.
- Stop at cost 0 or after 10000 steps; return the best state found.
- Swapping inside a box keeps the box constraint satisfied and limits
  the search space to 2 * 2 * 6 * 6 = 144 states.

Settings
  A: T0 = 1.0, alpha = 0.999  (medium start, slow cooling)
  B: T0 = 5.0, alpha = 0.99   (hot start)
  C: T0 = 0.1, alpha = 0.9    (cold start, almost hill climbing)

Observations
- All settings solved 100/100 runs, well under 10000 steps (max 227),
  since there are only 144 possible states.
- B was slowest (71.4 avg): at high T it often accepts worse moves
  (delta = +2 at T = 5 is accepted with p = 0.67).
- C was fastest (38.1 avg): it acts like hill climbing, which works since
  this puzzle has few local minima, but could get stuck on a harder one.
- delta = 0 moves are always accepted (exp(0) = 1), letting the search
  cross plateaus (steps 4-5 in the trace).
- Every run reaches the same solution as backtracking in 1(b)/(c).
